El proyecto

Temática

Elegimos el anime porque es una temática visual, con portadas llamativas que lucen muy bien en formato card. El sitio funciona como una vitrina del ranking de MyAnimeList.

Decisiones de diseño

La paleta usa un fondo azul noche (#0f172a) con cards en #1e293b, y dos acentos neón: rosa sakura (#f43f5e) y celeste (#38bdf8), inspirados en la estética de los posters de anime y las ciudades nocturnas japonesas. Las cards usan imágenes en formato póster (3:4), bordes redondeados y un hover con elevación y brillo rosado.

La API

Usamos Jikan API v4, una API pública no oficial de MyAnimeList que no requiere registro ni API key. Endpoint: https://api.jikan.moe/v4/top/anime?limit=12. La lista llega dentro de la propiedad data y cada anime trae su imagen, título, tipo, episodios, puntaje y géneros en una sola petición.

Lo técnico

  • HTML5 semántico en 3 páginas independientes con navegación y footer compartidos.
  • CSS mobile first con variables en :root y breakpoints en 320px, 768px y 1024px.
  • JavaScript con módulos ES (import/export): un archivo por tarea.
  • Fetch con async/await, try/catch y control de respuesta.ok.
  • Cards creadas con createElement y textContent.
  • Validación del formulario en el evento submit con alerts y reset.
