El proyecto

Temática

Elegimos las películas de Studio Ghibli porque son un clásico del anime, con pósters muy ilustrados que lucen muy bien en formato card. El sitio funciona como una vitrina de todas las películas del estudio, ordenadas según el puntaje de la crítica.

Decisiones de diseño

La paleta usa tonos suaves y pasteles, como los paisajes de las películas: un fondo verde menta (#f3f8f1), cards blancas y dos acentos, durazno (#f2a191) y celeste cielo (#8ecae6). Las tipografías son redondeadas (Fredoka y Nunito) para acompañar el estilo amable del estudio. Las cards usan el póster en formato 3:4, bordes redondeados y un hover con elevación y sombra durazno.

La API

Usamos la Studio Ghibli API, una API pública que no requiere registro ni API key. Endpoint: https://ghibliapi.vercel.app/films. Devuelve directamente un array con las 22 películas, y cada una trae su póster, título, director, año, duración y puntaje de la crítica en una sola petición. En el sitio se ordenan por puntaje y se muestran todas.

Lo técnico

  • HTML5 semántico en 3 páginas independientes con navegación y footer compartidos.
  • CSS mobile first con variables en :root y breakpoints en 320px, 768px y 1024px.
  • JavaScript con módulos ES (import/export): un archivo por tarea.
  • Fetch con async/await, try/catch y control de respuesta.ok.
  • Cards creadas con createElement y textContent.
  • Validación del formulario en el evento submit con alerts y reset.
